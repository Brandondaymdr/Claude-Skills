# Intent files

The front of the artifact chain (`intent.md` → optional spec → `plan.md` → diff) from Anthropic's AI-Native SDLC playbook, scaled to this repo per `DEFAULTS-ADR-0002.md`.

Write one for any piece of work that will outlive one session. Number them like ADRs (`0001-slug.md`), keep a `Status:` line (`Open` → `In progress` → `Done` / `Dropped`), and use the five sections in `0000-template.md`. `session-restart` sources contract items from `Status: Open` files here; `session-closeout` writes them for tee-up items that outlive the next session.
